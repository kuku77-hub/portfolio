# Biruk Dalecha — Portfolio (Next.js + React)

A responsive developer portfolio built with Next.js (App Router), React and TypeScript.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Edit your content
- `lib/content.ts` — skills, projects, stats, email and GitHub link
- `app/page.tsx` — page sections and text
- `app/globals.css` — colors, layout and responsive rules
- `public/profile.jpg` — your photo

## Before publishing
Replace the disabled project links (Live Demo / GitHub) in `app/page.tsx` when the projects are deployed.

## Publish for free
Push the project to GitHub, then import it on https://vercel.com (no configuration needed).
